# Bluestock Mutual Fund Analytics

## Project Overview

This project analyzes mutual fund data using Python, Pandas, SQLite and SQL.

## Objectives

- Clean mutual fund data
- Analyze NAV trends
- Analyze investor transactions
- Analyze fund performance
- Analyze AUM
- Store data in a SQLite database
- Perform analytical SQL queries

## Technologies

- Python
- Pandas
- NumPy
- SQLite
- SQL
- Matplotlib

## Database

Database file:

db/bluestock_mf.db

## Main Tables

- dim_fund
- dim_date
- fact_nav
- fact_transactions
- fact_performance
- fact_aum
